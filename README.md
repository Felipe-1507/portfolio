# felipeferreira.dev

Portfólio pessoal de [Felipe Ferreira](https://felipeferreira.dev) — desenvolvedor de sistemas, integrações de API e automação de processos.

Site estático de página única, escrito em HTML/CSS/JS puro (sem framework, sem build step), com navegação flutuante, abas de portfólio, fundo animado em canvas e carrossel de projetos com preview ao vivo via iframe.

## Seções

- **Sobre** — apresentação, idiomas e formação acadêmica com logotipos das instituições
- **Experiência** — histórico profissional
- **Portfólio** — abas de Projetos, Certificados (TOEIC B2), Conquistas e Tech Stack
- **Contato** — formulário direto (via Formspree) e links para e-mail, LinkedIn e GitHub

## Projetos em destaque

- **[NOME](https://nome.felipeferreira.dev)** — ERP financeiro e operacional (Node.js, TypeScript, PostgreSQL, Prisma)
- **[Filtros MercadoTurbo](https://filtros.felipeferreira.dev)** — análise de rentabilidade de anúncios do Mercado Livre (Python, Flask)
- **[PedidosTurbo](https://pedidos.felipeferreira.dev)** — painel operacional de vendas do Mercado Livre em tempo real (Node.js, WebSocket)
- **[Mirai Finance](https://mirai-finance.felipeferreira.dev)** e **[Mirai Fit](https://mirai-fit.felipeferreira.dev)** — produtos pessoais

Os três primeiros são sistemas internos de uma empresa; os links acima levam a versões públicas de demonstração, com dados fictícios.

## Stack

HTML5 · CSS3 · JavaScript · Canvas API · Formspree

## Manutenção e navegação

- `index.html`: conteúdo, estilos originais e funcionalidades existentes.
- `portfolio.css` e `portfolio.js`: navegação flutuante, novas abas, formação e grade de tecnologias.
- `assets/`: logotipos locais, sem dependência de serviços externos de ícones.
- Para adicionar certificados ou conquistas, edite os painéis correspondentes em `index.html`.
- Links diretos: `#projetos`, `#certificados`, `#conquistas` e `#habilidades`. O endereço `#tech-stack` também abre as habilidades.
- As abas aceitam setas esquerda/direita, Home e End, mantêm o histórico do navegador e usam os atributos ARIA de seleção e foco. A navegação principal destaca a seção visível.
- Preferências de movimento reduzido são respeitadas. Com JavaScript desativado, os conteúdos permanecem disponíveis na página.
